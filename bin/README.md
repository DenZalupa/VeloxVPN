# Ядро и драйверы

В эту папку кладутся два файла, которые нужны приложению для работы:

| Файл | Зачем |
|---|---|
| `sing-box.exe` | ядро, которое непосредственно держит VPN-соединение |
| `wintun.dll` | драйвер сетевого адаптера для TUN-режима |

Они **не хранятся в репозитории** (ядро весит ~80 МБ), а скачиваются
прямо из интерфейса приложения:

**Настройки → Ядро sing-box → Скачать официальное sing-box**
**Настройки → Сетевой драйвер TUN → Установить Wintun.dll**

Можно положить файлы сюда и вручную — приложение найдёт их автоматически.
Папка должна существовать, чтобы сборка PyInstaller проходила без ошибок,
поэтому в репозитории оставлен пустой каталог с этим файлом.
