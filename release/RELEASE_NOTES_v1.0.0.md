## Первый публичный релиз VeloxVPN

Конфигуратор VPN-подписок на ядре sing-box для Windows.

### Что в сборке

- Установка не требуется: распакуйте архив и запустите `VeloxVPN.exe`.
- Ядро sing-box и драйвер Wintun **не входят** в архив — приложение скачивает
  их при первом запуске (нужен доступ в интернет).
- Установка требует прав администратора (для TUN-режима и системного прокси).

### Возможности

- **Минималистичный главный экран** — одна большая кнопка подключения со
  статусами, рядом три метрики: тест пинга, замер скорости и live-скорость
  текущего соединения.
- **Импорт подписок** по ссылке, разбор vless / vmess / trojan / ss / hysteria2
  и других форматов, автоматическое определение страны сервера.
- **Дедупликация серверов** по каноническому ключу (протокол + нормализованный
  host + порт + transport + security + SNI + путь + ключ), а не по имени —
  повторы не занимают место в списке, а счётчик показывает, сколько исключено.
- **Сводка по подписке** прямо на главном экране: дата окончания, израсходованный
  и оставшийся трафик, процент пакета. Данные берутся из заголовка
  `Subscription-Userinfo` — если провайдер его не отдаёт, блок просто скрыт.
- **Тёмная и светлая темы**, переключатель в шапке, выбор сохраняется.
- Измерение пинга до всех серверов и замер скорости через CDN.
- Автовосстановление интернета, если после сбоя остался системный прокси,
  и скрипт «Починить интернет» в комплекте.

### Приватность

Подписки, ключи и конфигурация хранятся только локально в папке `data/`.
Телеметрии нет, секреты в логи не пишутся.

### Сборка из исходников

```bat
pip install -r requirements.txt
python -m PyInstaller --noconfirm --onedir --windowed --uac-admin ^
  --name VeloxVPN --icon app.ico ^
  --add-data "static;static" --add-data "bin;bin" main.py
```

Тесты: `python tests/test_all.py`.
